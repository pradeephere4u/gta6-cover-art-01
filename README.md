Neon Dusk Cover Studio — a web app that turns your own photo and a caption into GTA-style cover art: a multi-panel poster with a retro sunset sky, slit sun, skyline and palm silhouettes, bold gradient lettering, and a warm neon grade, exported as a PNG to share. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Load a photo into each panel (or one photo for every panel), crop and position it with the zoom and pan sliders, pick a layout, a grade and a size (1080 x 1080, 1080 x 1350 or 1920 x 1080), write your caption, and export a PNG. Everything runs offline in the browser — photos are read on your own machine and never uploaded. The two display fonts ship under app/fonts/ under the SIL Open Font License; no Rockstar logo, artwork or font is used.
